# 자동차 경주

## 프로그램 동작
1. `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)` 문구 출력
2. 자동차의 이름 입력 (쉼표(,) 기준으로 구분)
3. `시도할 횟수는 몇 회인가요?` 문구 출력
4. 시도할 횟수 입력
5. `실행 결과` 출력
6. **시도 횟수만큼** 자동차 이동 및 결과 출력
7. `최종 우승자 :` 문구 출력 후 최종 우승자 출력

## 기능 목록

- [x] 자동차 이름 입력
- [x] 시도 횟수 입력
- 시도 횟수만큼 자동차 이동
  - [ ] 0에서 9 사이에서 무작위 값 구하기
  - [x] 무작위 값이 4 이상인 경우 이동
- [x] 시도 횟수만큼 실행 결과 출력
- [x] 우승자 안내 문구 출력
  - 가장 많이 움직인 자동차가 우승
  - 우승자는 한 명 이상일 수 있음
  - 우승자가 여러 명인 경우 쉼표(,)를 이용하여 구분

## 예외 처리

`사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료`

- 자동차 이름 길이가 0이거나 5 초과인 경우
- 자동차 이름에 한글/영어가 아닌 다른 문자가 입력되는 경우
- 시도 횟수에 숫자가 아닌 값 입력
